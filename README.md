# Neopets Designer — updates

This is where the Neopets Designer gets its updates. There's nothing to download here by hand: a Designer that was shared with you looks here by itself when it starts (and twice a day after that), and its Home page says when a new version is ready — **Update now** or **Later**. Settings › About shows the version you have and has **Check now**.

An update only changes the program's own files. Your art, designs, creations and settings stay exactly as they are, and the files an update replaced are kept in the `data\updates` folder.
